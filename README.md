⚡ EKUM ELECTRICALS LTD

A modern, responsive website designed for EKUM ELECTRICALS LTD, an electrical engineering and contracting company based in Nigeria.

The website presents the company's services, projects, work process, and contact information through a professional and responsive interface.

🌐 Live Project

GitHub Repository:
https://github.com/ochejosephe/ekum-website

📌 About the Project

The EKUM ELECTRICALS LTD website was developed to provide the company with a professional online presence and make it easier for potential clients to understand its services and get in touch.

The design focuses on:

- Professional visual presentation
- Responsive layouts
- Clear service presentation
- Strong calls-to-action
- Mobile-friendly navigation
- Fast and clean user experience
- Modern electrical/engineering visual identity

✨ Features

- Responsive design for desktop, tablet, and mobile
- Professional hero section
- Company introduction
- Electrical engineering services section
- Project showcase
- Filterable project categories
- Step-by-step service process
- Contact section
- Call and WhatsApp contact options
- Mobile navigation
- Smooth animations and interactions
- SEO-friendly page structure

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- Git & GitHub
